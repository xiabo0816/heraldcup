# Herald Cup 首页 / Page Briefs: Home

本文件只定义首页的任务、结构和禁止项。布局实例见 10_page-blueprint.md，区块硬约束见 11_section-specs.md，首页不参与对象页的胶囊二级导航。

## 1. 首页 /

### 速查表

| 项目 | 要求 |
| --- | --- |
| 页面目标 | 在前两屏内讲清 Herald Cup 是一套把比赛、人物、战队和身份放回同一条主线的社区赛事门户 |
| 唯一主 CTA | 进入比赛中心 |
| 次 CTA | 查看人物档案、查看战队名册、进入我的主页 |
| 桌面端首屏 | 固定 3 + 6 + 3：左侧内容入口侧轨，中间内容主体，右侧身份轨 |
| 用户状态 | 游客、已登录未成为选手、已成为选手 |
| 第一性约束 | 首页继承顶部对象入口与顶部工具入口，但不复用对象页胶囊二级导航 |

### 必须区块

- 左栏内容入口侧轨：比赛中心、人物档案、战队名册、身份链路
- 中栏内容主体：顶部先讲平台定位与主 CTA，后接比赛中心、人物档案、战队名册、身份链路四个连续模块
- 右栏身份轨：登录前显示“登录后继续你的身份进度”；登录后显示账号、认领、队伍与邀请摘要；已成为选手时追加进入个人页的主动作
- Footer：品牌、对象频道入口、工具与规则入口、版权信息

### 禁止项

- 传统居中 Hero + 三张功能卡首屏
- 八张同等级大卡同时争主视觉
- 假数据照片墙、无来源宣传图、广告位式右栏
- 第二个首页入口墙式筛选区
- 在首页题头或中栏顶部复制比赛、选手、战队专属的胶囊二级导航

### 顺序与权重

- 游客态顺序固定为左栏入口侧轨 -> 中栏四模块主轴 -> 右栏登录引导
- 登录态顺序固定为左栏入口侧轨 -> 中栏四模块主轴 -> 右栏身份进度与邀请摘要
- 首页第一屏只能有一个绝对主重块，中栏始终是唯一主内容区
- 第二期增强内容只能排在一期主任务之后，不能挤占比赛、人物、战队和身份入口

### 硬约束

- 比赛中心模块必须展示当前赛季、对阵双方、状态和结果摘要，点击后进入比赛详情页，不能在首页内展开完整赛程表
- 人物档案模块必须展示人物名称、当前位置、当前归属与代表比赛摘要，点击后进入人物详情页，不展示完整档案
- 战队名册模块必须展示战队名称、当前杯赛归属、近期成绩或简介，点击后进入战队详情页，不展示完整阵容表
- 身份链路模块必须讲清登录、认领、建队与邀请的前后关系，并给到明确动作入口
- 右栏默认讲身份进度，不允许用 OpenDota 数据替代身份主线；如需显示数据摘要，也只能作为补充信息
- 无战队、无比赛、无认领状态时必须有明确空状态和下一步入口

### 首页材质补充

- 中栏主舞台必须是首页唯一最强材质块：可使用阵营光带、遗迹雾面和低噪点纹理，但不允许退回传统纯色 Hero 或满屏宣传图
- 左栏入口侧轨与右栏身份轨必须比中栏更克制，优先表现为稳定石板块面；它们可以有轻微主题提亮，但不允许复制中栏主舞台的强光带和大面积渐变
- 中栏四个连续模块应像嵌入主舞台的次级面板，而不是四张完全独立的普通卡；它们需要和主舞台共享同一家族的边线、底色和轻纹理来源
- 主舞台中的统计块和主 CTA 可以承接高光色，但高光只承担点亮作用，不允许把统计区做成金色大底或强饱和彩带
- 首页所有材质和纹理都必须服务“平台定位 -> 比赛 -> 人物 -> 战队 -> 身份”的阅读主线；如果装饰影响识别顺序，优先删装饰
- 首页的页面基础层必须完整跟随 Radiant 或 Dire，不允许把先锋杯、传奇杯、冠绝杯三色抬成首页主背景
- 若首页需要表达当前赛季或专题入口，只允许在对应模块局部使用杯赛色做标签、短条带、入口卡或专题 CTA；主 CTA 仍默认跟随当前主题的 `--primary`
- Radiant 首页应表现为自然、明亮、生命感；Dire 首页应表现为冷峻、压迫、硬核感，但两者都要先把比赛、人物、战队、身份四条主线讲清

### 第二期追加边界

- 允许追加社区主线摘要、最热话题或最新新闻卡、社区意义拼贴、英雄或内容型关系入口
- 追加位置必须晚于首页核心四模块
- 第二期内容不能替代首页第一期的比赛、人物、战队和身份主线

## 2. 首页移动端规则

### 必须保留

- 平台定位
- 比赛中心
- 人物档案
- 战队名册
- 身份链路
- 身份入口
- 登录后身份进度摘要

### 可收敛内容

- 比赛、人物、战队卡片改为单列轻卡
- 身份链路压缩为 2 到 3 条关键步骤
- 统计块改为双列或横滑

### 移动端底线

- 只允许重排任务顺序，不允许压缩桌面副本
- 顺序固定为内容入口 -> 主体内容 -> 身份入口 -> Footer
- Footer 仍然只承担收束和回流，不承担主 CTA 与范围切换
