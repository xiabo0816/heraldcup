# 今晚就来社区 / Page Briefs: Home

本文件只定义首页的任务、结构和禁止项。布局实例见 10_page-blueprint.md，区块硬约束见 11_section-specs.md，首页不参与对象页的胶囊二级导航。

## 1. 首页 /

### 速查表

| 项目 | 要求 |
| --- | --- |
| 页面目标 | 在前两屏内同时讲清平台价值、核心内容入口和身份入口 |
| 唯一主 CTA | 查看比赛中心 |
| 次 CTA | 查看比赛详情、查看选手详情、继续认领、进入我的主页 |
| 桌面端首屏 | 固定 3 + 6 + 3：左侧内容入口侧轨，中间内容主体，右侧身份轨 |
| 用户状态 | 游客、已登录未成为选手、已成为选手 |
| 第一性约束 | 首页继承顶部对象入口与顶部工具入口，但不复用对象页胶囊二级导航 |

### 必须区块

- 左栏内容入口侧轨：热门比赛、热门选手、社区玩法、社区赞助
- 中栏内容主体：顶部摘要与主 CTA，后接热门比赛、热门选手、社区玩法、社区赞助四个连续模块
- 右栏身份轨：登录前显示“快来登录”和登录收益；登录后显示 OpenDota 数据；已成为选手时追加参赛信息
- Footer：品牌、对象频道入口、工具与规则入口、版权信息

### 禁止项

- 传统居中 Hero + 三张功能卡首屏
- 八张同等级大卡同时争主视觉
- 假数据照片墙、无来源宣传图、广告位式右栏
- 第二个首页入口墙式筛选区
- 在首页题头或中栏顶部复制比赛、选手、战队专属的胶囊二级导航

### 顺序与权重

- 游客态顺序固定为左栏入口侧轨 -> 中栏四模块主轴 -> 右栏登录引导
- 登录态顺序固定为左栏入口侧轨 -> 中栏四模块主轴 -> 右栏 OpenDota 数据与参赛信息
- 首页第一屏只能有一个绝对主重块，中栏始终是唯一主内容区
- 第二期增强内容只能排在一期主任务之后，不能挤占主打比赛、主打选手和身份入口

### 硬约束

- 热门比赛区必须使用多条轮播，只展示名称、时间、状态、结果等摘要信息，不展示赛程表
- 热门比赛卡点击后必须进入比赛详情页，不能在首页内展开完整赛程
- 热门选手区必须使用多条轮播，只展示名称、Steam ID、擅长位置、擅长英雄、OpenDota 关键数据，不展示完整档案
- 热门选手卡点击后必须进入选手详情页
- 社区玩法模块必须并列展示先锋杯、传奇杯、冠绝杯三档要求，视觉权重一致
- 社区赞助模块必须展示核心作者“啵酱该吃饭了”，并展示其他赞助者头像与 ID
- 登录后默认显示 OpenDota 数据摘要；未成为选手时不展示参赛信息
- 无战队、无比赛、无 OpenDota 时必须有明确个人空状态

### 第二期追加边界

- 允许追加社区主线摘要、最热话题或最新新闻卡、社区意义拼贴、英雄或内容型关系入口
- 追加位置必须晚于首页核心四模块
- 第二期内容不能替代首页第一期主舞台和身份入口

## 2. 首页移动端规则

### 必须保留

- 平台定位
- 主打比赛
- 主打选手
- 社区入口
- 社区赞助入口
- 身份入口
- 登录后 OpenDota 数据摘要

### 可收敛内容

- 词云与封神榜压缩为轻卡
- 合作方改横滑或双列
- 社区画廊降低装饰密度

### 移动端底线

- 只允许重排任务顺序，不允许压缩桌面副本
- 顺序固定为内容入口 -> 主体内容 -> 身份入口 -> Footer
- Footer 仍然只承担收束和回流，不承担主 CTA 与范围切换
