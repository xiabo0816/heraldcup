# 今晚就来社区 / Page Briefs: Channel And Reading

本文件只保留第一期频道页、阅读页和静态说明页的任务边界。第二期频道与阅读页统一见 16_phase-two-features.md。

## 1. 频道页共享前提

- 比赛、选手、战队页统一继承顶部对象入口与顶部工具入口
- 全部、先锋杯、传奇杯、冠绝杯只作为顶栏下方的胶囊二级导航出现
- 首屏顺序固定为顶部导航 -> 胶囊二级导航 -> Banner（仅具体杯赛态，可选） -> 主工作台或主目录
- 顶部导航与胶囊二级导航之间不允许再插入频道标题条、PageIntro、Hero、目录题头或任何“比赛工作台 / 选手目录 / 战队目录”式独立头部
- “比赛工作台”“选手目录”“战队目录”这些词只允许出现在二级导航之后的正文首块标题、工作台标题或目录标题里，不得升格为二级导航上方的题头
- “全部”态不展示 Banner；切到具体杯赛态时，二级导航以下只进入当前杯赛的模块强调层：Banner、工具条、主区标题、右栏首卡和专题 CTA 可用杯赛色，页面基础背景、卡片底、边框与正文文字仍跟随 Radiant / Dire
- 首屏始终只有 1 个 Banner 槽位；正文不得再复制第二个 Banner
- 在比赛、选手、战队三个频道之间横向切换时，默认保留当前范围

## 3. 对象频道硬约束

### /matches

- 左 8 栏主工作台只展示当前范围内的赛程、赛季、阶段说明和结果入口
- “全部”态允许展示跨杯赛聚合赛程；某杯态只展示该杯赛程和赛季
- 右 4 栏改为“我与当前赛道的关系态右栏”，只解释我当前是否已经成为选手、是否已有战队、当前战队是否处在该赛道，不重复“当前范围”标题
- 比赛频道不直接暴露解散队伍、邀请入队、训练赛邀请等危险或跨对象动作

### /players

- “全部”范围展示全站选手目录；某杯态展示某杯选手池
- 选手卡必须显式展示所属杯池标签，不能只靠上下文暗示
- 右侧关系卡只说明我当前的人物绑定、认领进度和当前赛道关系，不把频道页改成操作页，也不在频道页直接发邀请

### /teams

- “全部”范围展示全站战队目录；某杯态展示某杯战队池
- 战队卡必须显式展示所属杯池标签
- 右侧动作卡只说明我当前的战队归属、是否已进入当前赛道以及下一步入口，不把频道页改成后台工作台

## 4. 频道页共享关系态

共享底线：频道页右栏先回答“我当前是否有选手身份”“我是否已有战队”“我当前是否处在这个赛道”，再给入口；不再使用泛化的队长工具卡，也不在频道页直接暴露危险操作。

## 4.5 频道与阅读页配色补充

- 对象频道的页面基础层先跟随 Radiant / Dire：背景、卡片、边框、正文和默认 CTA 都使用当前主题 token，不让杯赛色接管整页
- 三个杯赛 Banner 主色固定为：先锋杯 `#236D5C`、传奇杯 `#563880`、冠绝杯 `#853454`；对应渐变分别为 `#163F36 -> #236D5C -> #2E8C77`、`#34214F -> #563880 -> #6D4AA1`、`#552137 -> #853454 -> #A24569`
- 杯赛色只主导 Banner、模块入口、专题头图、模块标签和模块内 CTA；列表卡、关系卡和正文区继续以 Radiant / Dire surface 系列为主
- Banner 标题文字分别使用 `#F3FBF8`、`#F7F3FD`、`#FFF4F7`；副文案统一使用对应文字色的 82% 到 84% 透明度；模块内按钮可使用各自的 hover / 高亮色
- /rules、/guide 这类阅读与静态说明页不继承杯赛 Banner 系统；如果内容属于某杯赛，只通过 Badge、引用条、专题入口或轻 CTA 表达上下文

### /rules 内容口径补充

- /rules 必须把微信群公告整理成可阅读的站内规则页，至少分成四段：入群与语音、活动与参赛、社区秩序、日常提醒
- 入群与语音段必须明确昵称格式、Kook 服务器与语音频道的存在，以及“不会切区服、不会进语音都可以问”这类欢迎式说明
- 活动与参赛段必须说明固定节奏：每周三晚对黑、每周五晚比赛，以及先锋杯、传奇杯、冠绝杯、娱乐房、固定队建公会等社区参与方式
- 社区秩序段必须把底线写清：恶意吵架、恶意压力会被请出；禁止违法与广告；开玩笑要有分寸；高手菜鸟、男人女人都需要互相理解
- 日常提醒段必须保留社区照应感，例如观战时不要打扰选手、人多手杂注意保护自己、怕吵可折叠群聊、需要帮忙叫人时会 @ 所有人
- /rules 仍然是规则阅读页，不直接复制群公告原始 HTML 或表情素材；需要把公告语言转成站内一致的阅读文案
