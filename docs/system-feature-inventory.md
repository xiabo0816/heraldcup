今晚就来 - Dota2 社区赛事平台

完整前端设计文档（UI / 页面结构 / 功能布局版）

⸻

一、设计总方向

1.1 产品气质定义

你的站不适合做成“普通 SaaS 后台风”或者“白底蓝字资讯站”。

它更适合做成：

深色竞技底盘 + 社区荣誉氛围 + 内容化赛事门户

关键词是：
	•	深色
	•	竞技感
	•	荣誉感
	•	故事感
	•	社区归属感
	•	不是电竞馆官网，而是有长期文化沉淀的社区站

所以整体视觉建议：
	•	底色：Slate 深色系
	•	结构：稳、清晰、可扩展
	•	气质：不是花哨，而是“有压迫感的秩序”
	•	局部高光：赛事主题色、徽章、荣誉信息、结算页庆典感
	•	内容线与社区线：内嵌在比赛、选手、战队这些主对象里

⸻

1.2 视觉设计语言

基础底盘
	•	页面主背景：bg-slate-950
	•	次级模块底：bg-slate-900/60
	•	浮层 / 卡片底：bg-slate-900/40
	•	常规边框：border-slate-800
	•	重点边框：border-slate-700
	•	标题文字：text-slate-100
	•	正文文字：text-slate-300
	•	辅助信息：text-slate-400

赛事品牌色接入

先锋杯
	•	主色：emerald-400 / emerald-300
	•	辅色：sky-400 / sky-500

传奇杯
	•	主色：violet-400 / violet-300
	•	辅色：amber-400 / yellow-500

冠绝杯
	•	主色：rose-400 / rose-300
	•	辅色：amber-400 / amber-500

设计原则
	•	大面积使用深色底盘，颜色只在“重要内容”和“赛事身份”中出现
	•	不要让所有卡片都发光
	•	色彩优先服务：
	•	赛事分类
	•	状态区分
	•	CTA
	•	荣誉与结算

⸻

1.3 组件设计风格

建议 UI 形态参考：
	•	React + Tailwind + shadcn/ui
	•	用 Card / Tabs / Badge / Dialog / Sheet / Table / Tooltip / Accordion
	•	页面骨架用：
	•	Header
	•	Container
	•	Section
	•	Grid
	•	Sidebar
	•	Sticky Aside

卡片风格

统一建议：
	•	rounded-2xl
	•	柔和深色描边
	•	局部赛事主题色顶边或光晕
	•	标题区 + 内容区 + 底部动作区
	•	不做过强玻璃态，避免廉价 AI 感

动效建议
	•	首屏区块做 stagger reveal
	•	卡片 hover 做轻微抬升 + 阴影偏移
	•	Banner 做低强度渐变流动
	•	Tab 切换用柔和淡入
	•	结算页可加入更强仪式感动画

三、首页（重中之重）

你已经明确了：首页必须是左右结构，而且登录用户要直接看到：
	•	用户关键信息
	•	社区比赛信息
	•	OpenDota 信息

这个方向非常对。

首页应该是：
“平台主舞台 + 用户个人控制台”

⸻

3.1 首页布局结构

页面骨架

12 栅格双栏布局
	•	左侧主栏：col-span-8
	•	右侧侧栏：col-span-4

移动端：
	•	改为纵向堆叠
	•	右侧侧栏模块上移到主内容之间穿插展示

3.3 首页 UI 具体设计

A. 左侧 Hero 区

布局
	•	通栏大卡片
	•	左文案右视觉
	•	背景用低亮度赛事主题渐变 + 粒子纹理 + 柔和光斑

内容
	•	主标题：今晚就来
	•	副标题：Dota2 社区赛事平台
	•	小描述：从先锋到冠绝，每个人都能找到自己的比赛
	•	CTA1：查看当前赛季
	•	CTA2：进入比赛中心
	•	CTA3：加入社区 / 我的身份

视觉建议
	•	主标题用更有气质的展示字体
	•	描述用更稳的正文体
	•	Hero 区不能太满，要有压场空间

⸻

B. 左侧推荐赛季区

布局
	•	1 个大主卡 + 2~3 个小统计卡
	•	使用赛事主题色氛围底

功能
	•	赛季封面图
	•	赛季标题 / 届次
	•	类型（先锋 / 传奇 / 冠绝）
	•	阶段状态
	•	参赛队伍数
	•	比赛数
	•	阶段数
	•	CTA：进入赛季

⸻

C. 右侧用户身份卡

布局
	•	Sticky 吸附
	•	上部身份信息，下部状态与动作

登录态展示

用户状态	展示内容
未登录	平台介绍、登录注册按钮
已登录未绑 Steam	用户昵称、绑定 CTA
已绑 Steam 未认领	Steam 摘要、认领 CTA
审核中	认领申请状态、备注、时间
已认证选手	玩家头像、所属战队、身份徽章、我的比赛摘要

UI 建议
	•	卡片顶部可放身份徽章
	•	已认证状态使用主题高亮边框
	•	不同状态使用不同的 CTA 结构

⸻

D. 右侧 OpenDota 卡

布局
	•	上部核心数字
	•	中部常用英雄横排
	•	下部最近比赛列表

功能
	•	总战绩摘要
	•	近期胜负走势
	•	常用英雄
	•	最近比赛
	•	数据来源标签：live / cached

设计建议
	•	不做复杂图表也可以，先做简洁数字化概览
	•	英雄头像用圆形/方形徽章排布
	•	胜率可以做微型进度条

4.3 比赛总览 Banner 设计

Banner 目的
	•	建立赛事世界观
	•	让用户一进来就知道这里不是普通列表
	•	告诉用户先锋杯 / 传奇杯 / 冠绝杯是并存体系

Banner 内容
	•	标题：比赛中心
	•	副标：从先锋到冠绝，持续进行中的社区赛事图谱
	•	赛事入口 Chips：
	•	先锋杯
	•	传奇杯
	•	冠绝杯
	•	CTA：
	•	查看当前赛季
	•	浏览历史赛季

视觉建议
	•	背景用抽象地图 / 赛程纹理 / 网格光影
	•	不放复杂人物大图，避免俗套
	•	可做不同杯赛色带穿插

13.3 字体建议

你要求避免普通 AI 味很重的字体选择，这点非常对。
建议用：
	•	展示字体：更有竞技铭牌 / 荣誉标题感
	•	正文字体：更稳、更耐看

方向上可选：
	•	标题偏“硬朗、有雕刻感”
	•	正文偏“中性、清晰、适合长读”

不要用太泛滥的科技感模板字体去做全站。
