# 今晚就来社区 / Page Briefs: Detail, Operation, Admin

本文件只定义第一期详情页、操作页和后台页的任务边界。第二期详情页、英雄页和第二期后台统一见 16_phase-two-features.md。

## 1. 共享前提

- 详情页、操作页、后台页继承顶部对象入口与顶部工具入口，但不复制对象页胶囊二级导航
- 如果页面来自某个杯赛上下文，只通过 badge、标题说明、轻 Banner 或回流入口表达当前范围；页面基础层仍跟随 Radiant / Dire
- 详情页优先使用 8 + 4 或整宽叙事，不回退成长列表说明页
- 操作页与后台页必须把下一步、权限态和危险动作写清楚，不能只给静态布局

## 3. 详情页共享角色态右栏

共享底线：详情页右栏先回答“我是谁”“当前对象和我是什么关系”，再给动作；不允许继续复用频道页那种只按 visitor / user / player / captain 粗分的通用卡堆。

### 3.1 比赛详情 /matches/[slug]

| 当前关系 | 右栏应显示 | 不应显示 |
| --- | --- | --- |
| 自己不是选手 | 成为选手面板；说明登录后可继续认领并进入人物链路 | 当前比赛个人表现；无关队伍动作 |
| 自己是选手，且当前所在队伍在这场比赛涉及到的队伍中 | 我的比赛表现面板；按小局列出真实个人数据，至少包含英雄、KDA 和局内结果；未录入的小局必须明确写“暂未录入个人表现” | 成为选手 CTA；“你未参加当前比赛”提示 |
| 自己是选手，但当前不在这场比赛涉及到的队伍中 | 您未参加当前比赛面板；说明当前人物与这场比赛没有参赛关系 | 个人表现面板；与本人无关的邀请动作 |

### 3.2 选手详情 /players/[slug]

| 当前关系 | 右栏应显示 | 不应显示 |
| --- | --- | --- |
| 自己不是选手 | 成为选手面板；说明完成认领后再处理人物绑定 | 认领当前选手、入队或队伍动作 |
| 自己已绑定当前选手 | 这不是我按钮面板；必须明确这是解除当前人物绑定的入口 | “认领该选手”；“已绑定其他选手” |
| 自己已绑定其他选手 | 您已绑定 XXX 选手面板；强调当前账号已有唯一人物归属 | 当前人物认领 CTA；“这不是我”按钮 |
| 自己未绑定选手，且当前选手未认领 | 认领该选手面板；直接从当前人物上下文发起认领申请 | “已绑定其他用户”面板 |
| 当前选手已绑定其他用户 | 该用户基本信息面板；说明当前人物已经有账号归属 | 认领 CTA；“这不是我”按钮 |

### 3.3 战队详情 /teams/[slug]

| 当前关系 | 右栏应显示 | 不应显示 |
| --- | --- | --- |
| 自己不是选手 | 成为选手面板；说明完成认领后才能处理战队归属 | 申请加入、退出战队 |
| 自己已绑定当前战队 | 退出该战队按钮面板；明确当前就是本人队伍上下文 | “申请加入该战队”；“已绑定其他战队” |
| 自己已绑定其他战队 | 您已绑定 XX 战队面板；说明当前账号已有唯一战队归属 | 当前战队加入 CTA；退出当前页队伍动作 |
| 自己未绑定战队 | 申请加入该战队按钮面板；从当前战队上下文直接发起加入动作 | “退出该战队”；“已绑定其他战队” |

补充：详情页中的危险动作只允许通过确认链路进入；不在正文里直接执行。比赛详情页右栏不承担跨频道动作，选手与战队详情页右栏也不允许退化成频道页的泛化身份轨。比赛详情中的“我的比赛表现”必须来自选手级逐局表现数据，不允许再只用高光片段或文字说明伪装成统计面板。

## 5.5 配色底线

- 详情页默认使用 Radiant / Dire 的背景、surface、边框和文字体系；若处于具体杯赛上下文，可在题头摘要、资格 Badge、专题 CTA 中局部引入杯赛色
- 操作页默认跟随全站主题主色 `--primary`；登录、认领、我的主页不使用先锋杯、传奇杯、冠绝杯三色做页面主底
- 后台页只使用 Radiant / Dire 的中性色骨架与状态色；杯赛色最多用于数据标签、范围筛选当前态或内容来源标识，不用于整页大面积铺底
- 危险操作仍只使用 danger 语义，不借用杯赛红紫色制造伪风险感
