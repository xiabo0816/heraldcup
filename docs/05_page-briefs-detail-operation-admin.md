# 今晚就来社区 / Page Briefs: Detail, Operation, Admin

本文件只定义第一期详情页、操作页和后台页的任务边界。第二期详情页、英雄页和第二期后台统一见 16_phase-two-features.md。

## 1. 共享前提

- 详情页、操作页、后台页继承顶部对象入口与顶部工具入口，但不复制对象页胶囊二级导航
- 如果页面来自某个杯赛上下文，只通过 badge、标题说明或回流入口表达当前范围
- 详情页优先使用 8 + 4 或整宽叙事，不回退成长列表说明页
- 操作页与后台页必须把下一步、权限态和危险动作写清楚，不能只给静态布局

## 3. 详情页共享角色态右栏

| 角色 | 右栏应显示 | 不应显示 |
| --- | --- | --- |
| 游客 | 登录或浏览说明 | 身份动作 |
| 普通用户 | 基本用户信息、成为选手入口 | 建队、队长动作 |
| 选手 | 基本用户信息、选手信息、建立队伍入口 | 解散队伍 |
| 队长 | 基本用户信息、选手信息、队伍信息、与当前对象相关动作 | 无确认链路的危险动作 |

补充：比赛详情中的危险动作只允许通过确认弹层进入；不在详情页正文中直接执行。
